## [0.1.0] - 2026-06-19

### Added
- Weather tool for New York City
- Time tool with timezone support
- Google ADK agent integration
- Groq LLM (LLaMA 3.3 70B) integration
- Basic project structure

### Known Limitations
- Only supports New York City
- Hardcoded weather data
- No error handling
- No tests
- No observability
